LastWord is a Dead Man's Switch Vault: a secure cloud vault for critical instructions, passwords, and encrypted documents in S3 sealed with AWS KMS. You set a check-in frequency (30 days, or 2 minutes in demo mode). EventBridge and Lambda scan every minute. If you miss a check-in, the state machine escalates Active → Warned → Grace → Released. If silence continues, single-use expiring S3 links are delivered to trusted contacts.
